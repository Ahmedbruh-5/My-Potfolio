# Ahmed Aamir — Portfolio

Premium dark portfolio built with **React + Vite + Tailwind CSS + Framer Motion + Lenis**.

## Develop

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:5173](http://127.0.0.1:5173).

## Environment

Create `.env` in the project root:

```bash
VITE_FORMSPREE_ID=xzerkwjg
```

## Project screenshots

Drop images into:

- `public/projects/clipforge/`
- `public/projects/flick/`

Then add their paths to `images` in [`src/data/projects.ts`](src/data/projects.ts).

## Build

```bash
npm run build
npm run preview
```

Output is in `dist/`.
